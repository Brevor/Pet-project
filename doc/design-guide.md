> **Дата:** 2026-11-25
> **Роль:** Architect (визуальная система), при участии TechLead (задачи M15)
> **Основание:** `doc/proposal.md`, `doc/requirements/studio.md` (v0.10.0), `doc/requirements/profile.md`

## 1. Назначение

Единая визуальная система StudioFlow: токены, компоненты, правила для календаря, форм и списков,
требования доступности. Цель — убрать разнобой, который накопился в M0–M14 (сырые классы Tailwind
по месту, размеры 9–11px, popover с фиксированным `left: 25%`, отсутствие `focus-visible`).

Границы: только `client/`. API, схема БД и права не меняются. Новая библиотека компонентов
не вводится — компоненты живут в `client/src/ui/` на Tailwind (proposal §8: без UI-китов).

Ссылки на правила — `DG-N`, на них ссылаются задачи M15.

## 2. Принципы

1. **Плотно, но читаемо.** Основной экран — расписание; плотность 8/10, но минимальный размер
   текста в интерфейсе — 12px, в блоках календаря — 10px только для времени/метаданных (DG-12).
2. **Один акцент.** Брендовый violet — только действия и активные состояния; данные —
   нейтральная основа + цвет курса (DG-10).
3. **Сначала данные, потом декор.** Никаких градиентов, теней-«стекла» и анимаций, мешающих
   чтению сетки (DG-9).
4. **Состояние — не только цвет.** Отменённый сеанс, ошибка, конфликт имеют текст или иконку (DG-21).
5. **Права определяют разметку.** Недоступное действие отсутствует в DOM (ROL-11/ROL-12) —
   дизайн-гайд это не отменяет.
6. **Токены вместо значений по месту.** Цвет, радиус, тень, фокус — только через токены (DG-1).

### 3.2. Типографика

| Роль | Размер / вес | Где |
|---|---|---|
| Display | 24 / 600 | заголовок студии (h2) |
| Title | 20 / 600 | заголовки секций |
| Body | 14 / 400 | основной текст, формы, таблицы |
| Label | 13 / 500 | подписи полей |
| Caption | 12 / 400 | подсказки, метаданные |
| Calendar-time | 10–11 / 500, `tabular-nums` | время в блоках и gutter |
| Calendar-title | 12 / 600 | название курса в блоке |

- Шрифт: системный стек (`ui-sans-serif, system-ui, -apple-system, Segoe UI`), без загрузки
  веб-шрифтов (нет внешних зависимостей, FOUT исключён).
- `font-variant-numeric: tabular-nums` обязателен для времени и чисел в таблицах (DG-13).
- Минимум: 12px для текста, 10px — только время/метаданные в календаре; 9px запрещён (DG-12).

| Токен | Значение | Применение |

| `--space-1…8` | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px | сетка 4px |
| `--radius-sm` | 6px | поля, бейджи, блоки календаря |
| `--radius-md` | 10px | кнопки, инпуты |
| `--radius-lg` | 14px | карточки, секции |
| `--shadow-card` | `0 1px 2px rgb(15 23 42 / 0.06)` | карточки |
| `--shadow-pop` | `0 12px 32px rgb(15 23 42 / 0.16)` | поповер, меню |

| `--motion-pop` | 180ms ease-out | появление поповера |

`prefers-reduced-motion: reduce` — анимации отключаются, остаются мгновенные состояния (DG-23).

## 4. Компоненты (`client/src/ui/`)

| Компонент | Варианты | Обязательное |
|---|---|---|
| `Button` | primary / secondary / ghost / danger; sm 32px, md 36px, lg 40px | `focus-visible`, `disabled`, `type="button"` по умолчанию, иконка + текст |
| `IconButton` | ghost / danger, 32×32 | `aria-label` обязателен (DG-21) |
| `Field` (label + hint + error) | input / select / textarea | связь `htmlFor`/`id`, `aria-describedby` на hint и error (DG-20) |
| `Card` | surface, padding 16/24 | единый радиус и граница |
| `Tabs` | `role="tablist"`, `aria-selected`, `aria-controls` | активная вкладка не только цветом (DG-21) |
| `Table` | header, rows, numeric | `scope="col"`, `caption` (sr-only), выравнивание чисел вправо |
| `Badge` | role / status / count | фон `--brand-soft` или нейтральный |
| `Avatar` | img / initials, 24/32/40 | `alt` с именем, заглушка — инициалы (PRF-13) |
| `Dialog` | modal / popover / sheet | `role="dialog"`, `aria-modal`, Esc, возврат фокуса (DG-18) |
| `EmptyState` | icon + title + text + action | для пустых списков и недель |
| `Skeleton` | line / block / table | вместо текста «Загрузка…» (DG-26) |
| `InlineAlert` | info / success / warning / error | `role="status"`/`role="alert"`, `aria-live` (DG-21) |

Кнопки не меняют размер при нажатии; hover/active — только цвет/тень (DG-8).

## 5. Календарь расписания (главный экран)

### 5.1. Сетка

- Контейнер расписания — до **1440px** (сейчас `max-w-6xl` = 1152px сжимает 7 колонок, DG-24).
- Gutter времени — 48px, подписи 10–11px `tabular-nums`, выровнены по центру строки часа.
- Высота часа — 48–56px; шаг 15 минут — линия 1px `#F1F5F9`; час — `#E2E8F0`.
- Шапка дней — sticky, 32px, активный (сегодня) — `--brand-soft` + `--text` 600.
- Заливка колонки сегодняшнего дня — `--brand-soft` 40–60% (сейчас violet-50 — допустимо).

### 5.2. Блок занятия

| Свойство | Значение |
|---|---|
| Минимальная высота | **24px** (сейчас 16px, DG-14) |
| Фон | цвет курса с прозрачностью **12%** (сейчас 24%) |
| Левая полоса | 3px, цвет курса 100% |
| Радиус / граница | 6px, граница цветом курса 60% |
| Время | 10px mono, `tabular-nums`, `--text-muted` |
| Название | 12px / 600, одна строка `truncate`; при высоте ≥ 40px — две |
| Зал · преподаватель | 10px, только при высоте ≥ 48px |
| Отменён | `border-dashed` + подпись «отменён» 10px uppercase `--danger` |
| Выбран | `ring-2` `--focus`, без изменения размера |
| Доступность | `<button>` с `aria-label`: «Курс, 18:00–19:30, Зал А, преподаватель» |

Полный текст названия и все поля — в поповере, а не в обрезанном блоке (правило Text Reflow).

### 5.3. Цвет курса

- 12 фиксированных цветов (Q12); заливка 12%, полоса 3px, граница 60%.
- Текст на заливке — `--text` (проверить контраст ≥ 4.5:1 для светлых цветов; при необходимости
  затемнять текст до slate-900 и уменьшать прозрачность до 10%).
- Цвет не единственный носитель статуса: отмена — пунктир + текст (DG-21).

### 5.4. Линия «сейчас»

- 2px `--danger`, точка 6px, чип времени 10px `tabular-nums` на белом фоне с рамкой (сейчас 9px, DG-12).
- `z-index` ниже поповера; чип не перекрывает блоки.

### 5.5. Поповер сеанса

- Ширина 280px (сейчас 240px `w-60`), отступ 8px от блока.
- Позиционирование: справа от блока; если не помещается — **слева**; по вертикали — clamp в вьюпорт
  (сейчас `left: 25%` фиксирован, у правых колонок обрезается, DG-18).
- `role="dialog"`, фокус переходит внутрь, Esc и клик вне закрывают, фокус возвращается на блок.
- ≤ 767px — bottom sheet с затемнением 40–60%, а не карточка поверх сетки (SCH-20).

### 5.6. Адаптив

| Ширина | Поведение |
|---|---|
| ≥ 1280px | 7 дней, gutter + 7 колонок |
| 1024–1279px | 7 дней, минимальная колонка 96px |
| 768–1023px | 7 дней, горизонтальная прокрутка, gutter sticky (SCH-18) |
| ≤ 767px | один день + чипы дней, свайп, без горизонтального скролла |

### 5.7. Клавиатура и пустое состояние

- `Tab` — по блокам; `←/→` — соседний день; `↑/↓` — соседний слот; `Enter` — поповер; `Esc` — закрыть.
- Пустая неделя — `EmptyState` («На этой неделе сеансов нет» + «Создать занятие» по праву).
- Загрузка — скелетон сетки, не текст «Загрузка…» (DG-26).

## 6. Формы

- Ошибки — **у поля**: красная граница + текст 12px под полем + `aria-describedby` (DG-20);
  общий баннер остаётся только для сетевых ошибок.
- Серверные `details.fields.<поле>` раскладываются по полям (contracts §9), а не выводятся строкой.
- Подсказки формата: телефон «+7 916 123-45-67», соцсеть «https://…», «о себе» — счётчик `N / 500`.
- Email в профиле — `readOnly`, подпись «используется для входа» (PRF-2).
- Кнопка сохранения: `disabled` только во время запроса, текст меняется на «Сохраняем…»; после
  успеха — `InlineAlert` `role="status"` с автоскрытием 4 с и возвратом фокуса на форму.
- Загрузка аватара: превью до запроса, ограничение 2 МБ и типов на клиенте, прогресс/ошибка
  под кнопкой (PRF-11).

## 7. Списки и таблицы

- Таблица: `scope="col"`, `caption` sr-only, зебра не нужна — разделители `--border`.
- Строка команды: аватар 32px + имя (14/600) + email (12, muted) + роли-бейджи + действия.
- Действия: текстовая кнопка 32px или `IconButton` 32×32 с `aria-label` (DG-21); на мобильном —
  меню «⋯» с теми же действиями.
- Пустой список — `EmptyState` с подсказкой, как добавить первого участника (ученика — через ссылку).
- Длинные email — `truncate` + `title`.

## 8. Доступность (обязательный минимум)

- Контраст: основной текст ≥ 4.5:1, вторичный ≥ 4.5:1 при 14px, ≥ 3:1 для крупного.
- Тач/клик-таргеты ≥ 24×24 CSS px (WCAG 2.2 AA), основные действия — 32–40px (DG-22).
- `:focus-visible` — 2px `--focus` + offset 2 на всех интерактивных элементах (сейчас только
  `focus:border` у инпутов).
- Иконки-кнопки — `aria-label`; иконки декоративные — `aria-hidden`.
- Уведомления/ошибки — `role="status"`/`role="alert"` и `aria-live="polite"`.
- Клавиатура: полный обход календаря, поповера, меню; без ловушек; возврат фокуса.
- `prefers-reduced-motion` — отключение переходов (DG-23).
- Цвет не единственный индикатор статуса (DG-21).

## 9. Состояния экранов

| Состояние | Требование |
|---|---|
| Загрузка | скелетон (сетка/таблица/карточка), не текст |
| Пусто | `EmptyState` с объяснением и действием (по праву) |
| Ошибка | `InlineAlert` + кнопка «Повторить» |
| Нет студии | онбординг (ACC-5) — без изменения |
| Нет прав | элемент отсутствует в DOM (ROL-11) |
| Сохранение | кнопка `disabled` + «Сохраняем…», поля не блокируются |
| Оффлайн/таймаут | сообщение + повтор запроса |

## 11. Анти-паттерны

- emoji как структурные иконки; смешение семейств иконок.
- 9px текст, текст в блоке фиксированной высоты без альтернативы.
- Поповер с фиксированным смещением, выходящий за вьюпорт.
- Действия, доступные только по hover.
- Цвет как единственный индикатор статуса.
- Хардкод HEX/размеров по месту вместо токенов.
- `disabled` вместо отсутствия действия для прав (ROL-11).
- Анимации > 200ms в рабочем интерфейсе и параллакс в календаре.

## 12. Внедрение

Порядок — в `doc/tasks/progress.md` §4.14 (M15, T-80…T-86): токены и примитивы → календарь →
поповер → формы → таблицы → адаптив и шапка → a11y-проход.

Критерий готовности правки: используется только токен/компонент; поведение по правам не меняется;
`pnpm typecheck`, `pnpm lint` — 0; ручная проверка на 1440/1280/1024/768/375px; клавиатурный обход
календаря и поповера; контраст проверен на цветах курсов.
