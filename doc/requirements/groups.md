## 1. Назначение и границы

Группа — **набор учеников внутри курса** (поток): «Hip-Hop · начинающие · Пн/Ср». Группа нужна,
чтобы знать, кто должен быть на сеансе, и показывать ученику его состав. Группа не имеет
собственного расписания и преподавателя — они у курса и сеанса.

Входит: создание групп курса, зачисление/отчисление учеников, лимит по вместимости курса,
ростер сеанса, просмотр своей группы учеником, архивация.
Не входит: отдельное расписание группы, перенос ученика между курсами с сохранением истории,
автоматическое распределение, оплата.

## 2. Требования

| ID | Требование | Приоритет | Приёмка (Given → When → Then) | Источник |
|---|---|---|---|---|
| GRP-1 | Группа принадлежит курсу студии; создаётся владельцем, администратором или куратором (`courses.write`) | Must | Given куратор, When создаёт «Пн/Ср» у курса, Then группа видна в карточке курса | ответ 2026-11-25 |
| GRP-2 | Название группы: 2–80 символов, уникально в пределах курса без учёта регистра | Must | Given «Пн/Ср», When создаётся «пн/ср», Then 409 `GROUP_NAME_TAKEN`; 81 символ → 422 | по аналогии с CLS-2 |
| GRP-3 | В группу зачисляются только участники студии с ролью «ученик»; зачисление и отчисление — `courses.write` | Must | Given ученик студии, When куратор зачисляет его, Then он в составе группы; Given сотрудник, Then 422 `NOT_A_STUDENT` | STF-14 |
| GRP-4 | Ученик может состоять не более чем в одной группе одного курса; в разных курсах — без ограничений | Must | Given ученик в группе «Пн/Ср» курса X, When его добавляют в «Вт/Чт» курса X, Then 409 `ALREADY_IN_COURSE_GROUP`; в курс Y — успех | ответ 2026-11-25 |
| GRP-5 | Вместимость курса — справочное значение; лимита мест у группы нет, зачисление не блокируется (`courses.capacity` — только отображение) | Must | Given курс на 12 мест и 12 зачисленных, When добавляется 13-й, Then 409 `COURSE_CAPACITY_REACHED` | CLS-1 |
| GRP-6 | Ростер сеанса — ученики всех групп курса этого сеанса; сеанс не привязывается к отдельной группе | Must | Given курс с двумя группами по 5 учеников, When открывается сеанс, Then в ростере 10 учеников | ответ 2026-11-25 |
| GRP-7 | Ученик видит свою группу (название, курс, состав) в своём кабинете или карточке курса; чужие группы недоступны | Must | Given ученик группы, When открывает курс, Then видит «Моя группа: Пн/Ср, 8 человек»; группы других курсов не видит | ROL-10 |
| GRP-8 | Архивная группа не показывается при зачислении, её прошедшие отметки посещаемости сохраняются | Must | Given архивная группа, When открывается зачисление, Then её нет в списке | CLS-4 |
| GRP-9 | API: `GET/POST /studios/{id}/courses/{courseId}/groups`, `PATCH/DELETE .../groups/{groupId}`, `POST/DELETE .../groups/{groupId}/members` | Must | Given запросы, When выполняются с правами, Then 200/201/204; без прав — 403 | `contracts.md` (Architect) |

## 3. Влияние на схему и API

- Новые таблицы: `course_groups` (`studio_id`, `course_id`, `name`, `archived`, составной FK на
  курс), `course_group_members` (`studio_id`, `group_id`, `membership_id`, уникальность
  `(group_id, membership_id)` и правило «одна группа курса на ученика» — реализуется запросом
  или частичным индексом).
- Схема БД меняется → Decision Gate (`proposal.md` §10), миграция — задача Architect.
- Права: управление — `courses.write`; просмотр состава — участник группы и staff.

## 4. Открытые вопросы

| # | Вопрос | Почему важно |
|---|---|---|
| **GRP-Q1** | Нужен ли лимит мест именно у группы (например, «не больше 8»), или достаточно вместимости курса? | Влияет на схему и валидацию GRP-5 |
| **GRP-Q2** | Может ли ученик быть в группе курса, на который у него нет «записи»/абонемента? | Связь с балансом занятий (`balance.md`) |

## 5. Решения по открытым вопросам (2026-11-25)

Открытые вопросы закрыты ответами пользователя: лимита мест у группы нет (GRP-Q1); ученика можно зачислить без баланса (GRP-Q2); статуса «опоздал» нет (ATT-Q1); гость не отмечается сам, его отмечает администратор (ATT-Q2); отметки исправляет только администратор (ATT-Q3); отрицательный баланс запрещён (BAL-Q1); срок действия пакета нужен (BAL-Q2); внутреннее уведомление о достижении нужно (ACH-Q1); предустановленный каталог достижений нужен (ACH-Q2).
