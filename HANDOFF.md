## 4. Решения и факты

- Стек: TypeScript, Fastify 5, PostgreSQL 18, React 18 + Vite + Tailwind, JWT, `@node-rs/argon2`.
- Роли: `owner`, `admin`, `curator`, `teacher`, `assistant`, `student`; права — объединение ролей.
- Изоляция: `studio_id` во всех студийных таблицах, составные внешние ключи на `(studio_id, id)`.
- Маршруты API: база `/api/v1`; публичные — `/health`, `/auth/*`, `/join/{code}`, `/join/{code}/register`.
- Схема подтверждена пользователем **2026-11-22**: разрешено добавить `courses.teacher_membership_id`.
  Таблица заявок преподавателей **не нужна** (Q9 закрыт).

## 5. Что нужно от Architect

1. **Миграция 006** для `courses.teacher_membership_id`:
   - тип `uuid NULL`, внешний ключ на `memberships (studio_id, id)`, `ON DELETE SET NULL`;
   - индекс не нужен для курсов, но проверка «участник той же студии и с ролью teacher» — на уровне
     сервиса (БД это не выражает);
   - изменение согласовано, Decision Gate закрыт.
2. **Контракты:**
   - `POST /studios/{id}/courses` и `PATCH …/courses/{courseId}` — поле `teacherMembershipId` (nullable);
   - ответы курсов содержат преподавателя (`teacherMembershipId`, `teacherName`);
   - `POST /sessions` и `PATCH /sessions/{sessionId}` — **убрать `durationMin`**, длительность берётся
     из `courses.default_duration_min`; передача `durationMin` → `422 VALIDATION`;
   - ошибки `NOT_A_TEACHER` при неверном преподавателе курса.
3. **Зафиксировать в архитектуре поведение при изменении длительности курса:** существующие сеансы
   сохраняют свою длительность, новые — получают новую.
4. **UI-требования** (ROL-11/12, STF-11, ROM-7) — не архитектурное решение, но TechLead должен
   получить список элементов, скрываемых по матрице 4.1.

## 6. Ограничения среды

- `pnpm run` не спавнит процессы в песочнице — тесты запускаются напрямую через node.
- `vite build` локально не выполняется (esbuild), сборка клиента — только в Docker.
- Git push из агентской среды недоступен; ветка пушится вручную.
- Локальная БД: `postgres://postgres@127.0.0.1:5432/studioflow`; контейнерная — том `pgdata`.
