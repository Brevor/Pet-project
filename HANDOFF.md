## 1. Что изменилось в v0.5.0

Запрос пользователя: **расписание должно отображаться недельным календарём**, а не списком.
SCH-6 переписан, добавлены SCH-11…SCH-18.

| # | Что | Требования |
|---|---|---|
| 1 | Основной вид расписания — сетка «дни Пн–Вс × время»; сеанс в своём дне, начало по минуте, высота пропорциональна длительности | SCH-6, SCH-11 |
| 2 | В блоке сеанса: курс, зал, преподаватель, начало–окончание; в узком блоке минимум время и курс, остальное в карточке по клику | SCH-12 |
| 3 | Навигация по неделям: «предыдущая/следующая/сегодня», подпись диапазона дат, подсветка текущего дня | SCH-13 |
| 4 | Параллельные сеансы делят ширину колонки дня, порядок стабилен | SCH-14 |
| 5 | Отменённые сеансы остаются с пометкой и не блокируют слот | SCH-15 |
| 6 | Действия (создать/перенести/отменить/удалить) — только по `schedule.write`; у остальных элементов нет в разметке | SCH-16 |
| 7 | Видимая шкала — рабочие часы студии; ночные сеансы расширяют шкалу, не обрезаются молча | SCH-17 |
| 8 | Адаптивность: горизонтальный скролл дней, липкая шапка | SCH-18 |

Не менялись: создание/правка серии, конфликты, длительность из курса, права на API.

## 2. Решения Analyst, важные для архитектуры

- **Схема БД и API не меняются.** Неделя запрашивается существующим `GET /schedule`
  с `from`/`to` этой недели; новых эндпоинтов и полей нет.
- **Границы недели** — Пн 00:00 … Вс 23:59 в часовом поясе студии (`studios.timezone`),
  это уже зафиксировано в `architecture.md` §7 и `contracts.md` §7 (v1.3.1).
- **Дневной вид** отдельным требованием не является — открытый вопрос **Q10** (§9 studio.md).
- **Роли:** календарь видят все шесть ролей (SCH-7), действия — только `schedule.write`
  (owner/admin/curator), у teacher/assistant/student управляющих элементов нет (ROL-11).

## 4. Ограничения среды

- `pnpm run` не спавнит процессы в песочнице — проверки через `node` напрямую.
- `vite build` локально не выполняется; сборка клиента — в Docker.
- Git push из агентской среды требует выхода из песочницы; ветку пушит пользователь
  (сейчас запушена вручную, PR #8 открыт).
